# Security Policy / 보안 정책

[English](#english) · [한국어](#한국어)

## English

### Supported version

Security fixes are provided for the latest published release. Please reproduce the
problem on the newest stable version before reporting it when possible.

### Reporting a vulnerability

Do not open a public issue for a vulnerability. Use GitHub's
[private vulnerability report](https://github.com/AIEGOBOT/ComfyUI-VideoComparer/security/advisories/new)
and include the affected version, impact, reproduction steps, and any suggested fix.

Do not include real credentials or private media. A minimal synthetic workflow is
preferred. You should receive an initial response within seven days.

## 한국어

### 지원 버전

보안 수정은 가장 최근에 공개된 버전을 기준으로 제공합니다. 가능하면 최신 안정
버전에서도 문제가 재현되는지 확인한 뒤 신고해 주세요.

### 취약점 신고

취약점은 공개 이슈로 작성하지 마세요. GitHub의
[비공개 취약점 신고](https://github.com/AIEGOBOT/ComfyUI-VideoComparer/security/advisories/new)를
사용하고 영향받는 버전, 영향 범위, 재현 순서와 제안하는 수정 방법을 적어 주세요.

실제 인증 정보나 개인 미디어는 포함하지 마세요. 최소한의 합성 워크플로우를
권장합니다. 최초 답변은 7일 이내를 목표로 합니다.
